Écosystème Modulaire GSI

Guide Officiel Hephaistos

Spécifications architecturales, protocole IPC inter-modules et directives de design unifiées pour l'écosystème de portage Android.

1. Philosophie & Règle Absolue

L'écosystème Hephaistos est une suite d'outils modulaires indépendants dédiés à la manipulation, à l'extraction et au portage automatique de GSI (Generic System Image) et de partitions système (sparse, raw, erofs, ext4).

  • Package universel : Chaque application future DOIT avoir pour package com.hephaistos.<nom_application>.
  • Zéro Interface Indépendante Anarchique : Les applications futures sont des moteurs headless ou services qui s'appuient à 100% sur les composants et directives d'interface unifiés fournis par Hephaistos.
  • Auto-Documentation Obligatoire : Chaque application doit embarquer son fichier manifest.json décrivant rigoureusement ses commandes, ses arguments et son format de sortie JSON.

2. Protocole de Communication (IPC)

Les applications communiquent sans couplage de code source grâce aux Intents Android et charges utiles JSON :

Action d'Exécution : com.hephaistos.action.EXECUTE

val intent = Intent("com.hephaistos.action.EXECUTE").apply {
    setPackage("com.hephaistos.unpacker")
    putExtra("EXTRA_COMMAND", "unpack")
    putExtra("EXTRA_PAYLOAD", """{"input_path":"/sdcard/system.img"}""")
    putExtra("EXTRA_REQUEST_ID", "req_123456")
    putExtra("EXTRA_SENDER", "com.hephaistos.launcher")
}
context.sendBroadcast(intent)

Action de Résultat : com.hephaistos.action.RESULT

val resultIntent = Intent("com.hephaistos.action.RESULT").apply {
    setPackage(senderPackage)
    putExtra("EXTRA_REQUEST_ID", requestId)
    putExtra("EXTRA_STATUS", "SUCCESS")
    putExtra("EXTRA_RESPONSE_JSON", """
    {
        "status": "SUCCESS",
        "partitions": ["system", "vendor", "product"],
        "durationMs": 1450
    }
    """.trimIndent())
}
context.sendBroadcast(resultIntent)

3. Directives d'Interface Unifiées (UI / UX)

Toutes les règles d'interface suivantes sont intégrées et standardisées par Hephaistos :

Composant Standard Hephaistos Rôle
Accueil Minimaliste Centré sur la tâche principale sans surcharge visuelle.
Cartes d'options OptionCard Carte Material 3 avec nom, icône à gauche et toggle optionnel.
Sélecteur de fichiers FilePickerDialog Champ de saisie ouvrant le gestionnaire en popup modale.
Disposition Grille ou Liste Bascule simple entre vue grille et vue liste verticale.
Toggles & Switches M3 Switch Pour les options booléennes de traitement (sparse, compression).
Notifications Progress Notification Intégration de toute tâche de fond dans la barre de notifications Android.
Terminal Console Hephaistos Exécution directe et capture des logs dans la console centrale.

4. Modèle de Manifeste (manifest.json)

Voici le format strict que tout moteur ou agent IA doit fournir :

{
  "$schema": "https://hephaistos.dev/schemas/module-v1.json",
  "moduleId": "com.hephaistos.unpacker",
  "name": "Hephaistos Image Unpacker",
  "version": "1.0.0",
  "description": "Moteur d'extraction d'images sparse et raw",
  "commands": [
    {
      "name": "unpack",
      "description": "Déballe une image système en partitions réelles",
      "parameters": [
        { "name": "input_path", "type": "string", "required": true },
        { "name": "output_dir", "type": "string", "required": true }
      ],
      "outputFormat": {
        "status": "string",
        "partitions": "array of strings"
      }
    }
  ]
}
